# 反物质维度 HoldKeys Mod v1.2.0

这是一个适用于 Steam Windows 版《反物质维度》的内置自动长按 Mod。它通过 Electron 主进程定时向游戏页面发送按键脉冲，不依赖最小化窗口内部的渲染计时器，因此不需要粘滞键，也不要求游戏窗口始终置顶。

## v1.2.0 变化

- 新增两个长按按键：`R`（复制器星系，面板快捷键 `F11`）和 `E`（永恒，面板快捷键 `F12`）。
- 悬浮窗页面整体重置并重做：所有颜色、边框、圆角改用游戏自身的 CSS 变量，**自动跟随游戏内任何主题**（默认暗色、Dark、AMOLED、Metro 直角、浅色等），字体继承游戏正文（Typewriter，中文环境带楷体回退）。
- 悬浮窗的保存状态（位置、最小化）升级到新的存储键，旧状态自动清除——升级后悬浮窗回到默认位置与外观。
- 安装器彻底重构为**按结构特征识别兼容性**（游戏必需文件、`version.txt` 版本、`app.js` 内快捷键绑定签名、index.html 锚点、mod 标记），不再钉整文件哈希：
  - 中文补丁更新（如翻译 catalog 更新）后无需等 mod 适配，直接安装即可。
  - 同时支持**未安装汉化补丁的原版游戏**。
  - 已安装 1.1.1 的游戏可就地升级，无需先卸载。
- 卸载器改为外科式清理：按注入痕迹移除 mod 的 index.html 注入、3 个 mod 文件和 main.js 挂钩；main.js 恢复优先使用安装时保存的原件副本，其次按特征反向剥离，最后使用 mod 内置的原版 main.js 副本。
- `main.js` 的挂钩改为安装时按锚点动态注入，不再整文件覆盖游戏文件。
- 首次安装时会做一次 app.asar 全量备份到状态目录，作为兜底回滚点。

## 支持版本

- Steam App ID：`1399720`
- 测试游戏版本：`11.5`（Steam Build ID `16370635`）。其他版本只要结构特征校验通过也能安装，但未经过测试。
- 汉化补丁：可选。`0.3.2` 及其后续更新、或完全没有补丁的原版游戏均可安装。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `F6` | 开关 D：维度提升 |
| `F7` | 开关 M：全部最大 |
| `F8` | 开关 C：大坍缩 |
| `F9` | 开关 G：反物质星系 |
| `F11` | 开关 R：复制器星系 |
| `F12` | 开关 E：永恒 |
| `F4` | 停止全部长按 |
| `F10` | （游戏自带）全屏切换，与本 Mod 无关 |

面板可以拖动。点击标题栏右侧的最小化按钮后，面板会收纳到左下角；再次点击小标签将恢复完整面板，并回到最小化前的位置。

## 使用前提

- 游戏内选项需要开启快捷键（默认开启）。
- `R` 在复制者未解锁时没有效果；`E` 如果开了永恒确认，确认弹窗由游戏原逻辑处理。
- 弹窗、进度条、文本输入框聚焦时，快捷键是否生效由游戏原逻辑决定。

## 安装

1. 完全退出《反物质维度》。
2. 双击 `Install-HoldKeys.cmd`。
3. 如果游戏目录没有写入权限，请右键 `Install-HoldKeys.cmd`，选择“以管理员身份运行”。
4. 安装成功后从 Steam 正常启动游戏。

从 1.1.1 升级：直接运行当前安装器即可就地升级，无需先卸载。

更早版本或状态异常时：先运行对应版本的卸载器（或本卸载器清理残留），再运行当前安装器。

## 检查与卸载

- 双击 `Check-HoldKeys.cmd`：只读检查当前状态，不修改文件。
- 双击 `Uninstall-HoldKeys.cmd`：按注入痕迹完整移除本 Mod。

卸载前同样需要完全退出游戏。

## 更新游戏或中文补丁

正常情况下（本 Mod 已卸载或已安装均可）：

1. 完全退出游戏。
2. 更新游戏或中文补丁。
3. 重新运行 `Install-HoldKeys.cmd`：如果当前已安装本 Mod，安装器会先清理旧注入再装新版；如果从未安装或已卸载，会直接安装。

如果结构校验失败（例如游戏大改版），安装器会明确报错并保持原文件不变，不会强行修改。

## 说明

- Mod 不读取或修改游戏存档。
- Mod 不直接修改玩家数据，只触发游戏原有的可重复快捷键。
- 主进程只负责定时脉冲；按键是否生效仍由游戏页面中的原有快捷键条件决定。
- 状态目录：`%LOCALAPPDATA%\AntimatterDimensionsHoldKeysMod`（state.json、main.js 原件副本、首次安装的全量备份）。
